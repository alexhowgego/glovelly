## Create a gig

<a class="menu-link" href="https://menu.glovelly.net">Open Glovelly Menu to create a gig</a>

1. Open **Gigs** and choose **Create gig**.
2. Select the client.
3. Choose the work type and add a title or description.
4. Add the location, date, fee, and status.
5. Save the gig.

Use **Planned** for confirmed future work, **Completed** once it is finished, **Cancelled** when it will not go ahead, and **Draft** while the details are still taking shape.

## Add useful context

You can add notes, driving mileage, passengers, expenses, receipts, and linked resources to a saved gig. Keep the detail with the work so it is ready when you invoice it.
