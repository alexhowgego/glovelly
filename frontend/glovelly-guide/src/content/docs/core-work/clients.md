## Add a client

<a class="menu-link" href="https://menu.glovelly.net">Open Glovelly Menu to add a client</a>

1. Open **Clients** in Glovelly Menu.
2. Choose **Add client**.
3. Enter the client name, billing email, address line 1, and city. Add the remaining address details when you have them.
4. Save the client.

The client is now available when you create a gig. Their email and billing details can be used when you create an invoice.

## Keep details useful

Open a client to update their details when they change. Client settings can also hold invoice filename, email-subject, payment-window, and mileage defaults for that client.

:::tip
Add the billing email you actually expect to use before sending an invoice. It is easier to check once here than to correct a delivery later.
:::
