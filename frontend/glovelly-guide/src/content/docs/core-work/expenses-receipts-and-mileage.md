## Add an expense

<a class="menu-link" href="https://menu.glovelly.net">Open Glovelly Menu to record an expense</a>

1. Open the saved gig.
2. Add an expense with a clear description and amount.
3. Attach a receipt if you have one.
4. Save the expense.

A saved receipt stays with that expense. You can download or remove the attachment later without changing the expense's reimbursement state.

## Record mileage

1. Edit the gig and select **I was driving for this gig**.
2. Enter travel miles and any passenger count.
3. If available, use **Estimate mileage**, then check and adjust the result before saving.

Mileage uses the applicable saved rate when an invoice is generated. If mileage estimation is unavailable, you can still enter the miles yourself.

## Claimable or reimbursed

Claimable expenses can appear on a newly generated invoice. Mark an expense **Reimbursed** when it has already been paid back; it is then excluded from new invoice lines by default.
